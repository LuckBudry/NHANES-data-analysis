# NHANES Data Analysis

This repository contains the code, data, figures, and reports created for the analysis of NHANES datasets as part of Assessments 2 and 3.

## Purpose

The purpose of this repository is to organize and document the work of data preparation, analysis, and visualization that was done on the NHANES datasets.

## Repository Structure

### `data/`
Contains the original NHANES datasets used for the analysis, as well as `cleaned_NHANES.csv`, the final dataset obtained after merging and cleaning the data.

### `figures/`
Contains the figures and visualizations created during the data analysis.

### `scripts/`
Contains the R Markdown (`.Rmd`) and R (`.R`) files used for Assessments 2 and 3, as well as the rendered HTML files.
The updated report from this week's exercise 2 (`assessment_week_3.html`)
The dashboard from exercise 3 (`nhanes_dashboard.html`)

### `reports/`
Contains the final PDF reports submitted for Assessments 2 and 3.
